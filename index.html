Đang kiểm tra máy chủ…
🔵 Máy chủ riêng — nơi cất khoá Google

Khoá Google Places nằm trong biến môi trường trên máy chủ, không bao giờ gửi xuống trình duyệt. Máy chủ cũng là thứ giải mã được link rút gọn maps.app.goo.gl — việc mà trình duyệt bị CORS chặn.

Để trống nếu web và API chạy cùng domain (trường hợp Vercel thông thường). Chỉ điền khi tách domain, ví dụ https://foodguide-api.vercel.app/api/place.

🟢 OpenStreetMap — dự phòng, luôn bật

Khi không có máy chủ (ví dụ mở thẳng file index.html), trang vẫn tra được địa chỉ và quận từ toạ độ. Không lấy được số sao và lượt đánh giá — dữ liệu đó chỉ Google mới có.

Cách dựng máy chủ & lấy khoá Google (khoảng 10 phút)

Bước 1 — Tạo khoá Google Places API

  1. Vào Google Cloud Console → tạo một Project.
  2. Mở APIs & Services → Library, bật Places API (New).
  3. Vào Credentials → Create credentials → API key, sao chép khoá.
  4. Bấm Edit API key → Application restrictions chọn None (khoá dùng ở phía máy chủ nên không giới hạn theo domain trình duyệt được).
  5. API restrictions → giới hạn đúng Places API (New).
  6. Vào Billing → Budgets & alerts đặt ngân sách cảnh báo để không bị phát sinh chi phí ngoài ý muốn.

Bước 2 — Deploy lên Vercel

  1. Đẩy mã nguồn lên GitHub (file .env đã bị .gitignore chặn, khoá không lên theo).
  2. Vào vercel.com/new → chọn repository → Deploy.
  3. Mở Settings → Environment Variables, thêm:
    GOOGLE_MAPS_API_KEY = khoá vừa tạo.
  4. Vào tab Deployments → Redeploy để biến môi trường có hiệu lực.

Chạy thử ở máy

  1. npm i -g vercel
  2. Tạo file .env theo mẫu .env.example, điền khoá.
  3. vercel dev → mở http://localhost:3000

🔒 Khoá chỉ nằm trong biến môi trường của máy chủ. Trình duyệt gọi /api/place và nhận về dữ liệu đã xử lý — không có bất kỳ phần nào của khoá trong phản hồi. Endpoint có sẵn giới hạn 30 lượt/phút cho mỗi IP và chỉ nhận link thuộc domain Google Maps.
